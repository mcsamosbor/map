## Цель проекта

Разработка SPA карты для необычного майнкрафт сервера с уникальной генерацией:

Мир поделен на блоки `BlockData` - прямоугольники с масштабом 2 к 1, если смотреть сверху они могут распологаться вертикально или горизонтально

Блок делится на этажи - на этаже может быть какая нибудь структура `PlaceData`.

Этажей может быть разное количество, нумеруются от минимального до максимального

Отображаемые этажи бывают обычные, двойные (`double_floors`, подэтажи `N/1`, `N/2`) и тройные (`triple_floors`, подэтажи `N/1`, `N/2`, `N/3`); списки не пересекаются. `floors_data` индексируется ФИЗИЧЕСКИМИ слотами (помогают хелперы `getExtendedFloors`, `getFloorHeight`, `getMaxFloorSlot`, `getFloorDisplayBySlot` в `src/types/block.ts`)

Каждый этаж состоит из проходов `PassageData`, которые могут иметь разную конфигурацию

Блоки соединяются друг с другом через переходы `TransitionData`

Карту заполняют игроки-добровольцы, доступа к серверу майнкрафта нет

## Стек

- Vite
- Typescript - обязательна типизация всего что только можно
- Vue3 - интерфейс
- Pixi.js
- На данный момент основная база данных в Supabase - различные проверки прав, реалтайм

## Команды

Не запускать dev-сервер (`npm run dev`) если не просят

Не запускать сборку (`npm run build`) если не просят

Разрешается и рекомендуется после написания кода запускать форматирование `npm run format`

## Структура проекта-папок

- `supabase/` - тут описывается база данных supabase, её настройки и миграции

- `src/components` - визуальные компоненты

  `/canvas` - вьюпорт, слайдер слоев, канвас

  `/card` - все что связано с карточкой блока

- `src/const/rendering` - константы рендеринга блоков, проходов, переходов

- `src/renderer` - отвечает за рендеринг на канвас

  `/BlockView.ts` - рендер блока и его внутренностей

  `/contextCache.ts` - кэш текстур и геометрий

  `/MapRenderer.ts` - рендер карты, блоков, переходов и прочего

- `src/repository` - репозитории, пока два вида - локальный тестовый(`mock_repo.ts`) и продовый(`supabase_repo.ts`)

  `/manager.ts` - менеджер репозиториев, в нем методы переключения между ними

- `src/stores` - все pinia сторы

  `/authorization.ts` - отвечает за авторизацию и геттеры прав

  `/blocks.ts` - хранит блоки

  `/transitions.ts` - хранит переходы

  `/comments.ts` - хранит комментарии

  `/canvasContext.ts` - используется для контекстного меню при ПКМ по канвасу

- `src/types` - различные типы
- `src/views/mobile` - вид сайта для мобильных устройств
- `src/views/pc` - вид сайта для ПК
